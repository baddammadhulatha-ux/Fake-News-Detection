# 📰 Fake News Detection Using Machine Learning

A machine learning project that detects whether a news article is **Fake or Real** using Natural Language Processing (NLP).

## 🚀 Features

- Text preprocessing and cleaning
- TF-IDF text vectorization
- Logistic Regression classification
- Fake/Real news prediction
- Simple Gradio web interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- TF-IDF
- Logistic Regression
- Gradio
- Google Colab

## 📊 Project Workflow

News Article
↓
Text Cleaning
↓
TF-IDF Vectorization
↓
Logistic Regression
↓
Prediction
↓
Fake ❌ / Real ✅

## 📁 Project Files

- `app.py` – Gradio prediction application
- `fake_news_model.pkl` – Trained machine learning model
- `tfidf_vectorizer.pkl` – TF-IDF vectorizer
- `requirements.txt` – Required Python libraries
- `README.md` – Project documentation
